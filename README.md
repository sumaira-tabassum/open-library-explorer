# 📚 Book Explorer

A simple React application that lets users search for books using the Open Library API and view additional details through an interactive modal.

## Features

* Live book search
* Dynamic book cards
* Detailed modal view
* Loading indicator during API requests
* Placeholder images for unavailable book covers
* Load more functionality

## Built With

* React.js
* Axios
* CSS
* Open Library API

## Getting Started

```bash
npm install
npm start
```

## What I Learned

This project helped me practice React components, state management, API integration, asynchronous JavaScript, and building responsive user interfaces.

## Deployment

The application is deployed using Netlify.
